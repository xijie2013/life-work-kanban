☁ 云同步设置

看板数据存在 GitHub Gist 上，跨设备自动同步。
配置只需做一次，凭据仅存在本机浏览器（不会发送到任何第三方）。
gist.github.com 上你创建的 secret gist 的 URL 末尾那串。
GitHub → Settings → Developer settings → Personal access tokens → classic → Generate new token，scope 只勾 gist。
高级 / 故障排查

• Token 失效或泄漏时，去 GitHub 撤销 + 生成新的，再回来更新这里。

• 数据全部存在 Gist 上；浏览器 localStorage 只存：① 这两个凭据 ② 一份本地缓存（用于离线快速渲染）。

• 若本机出现奇怪状态，可点下方 清除并重置 重新开始（不会删云端数据）。
